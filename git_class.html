1) Les bases

Initialiser un dépôt, vérifier l’état, comprendre ce qui est suivi.

Initialisation

Créer un dépôt

À faire une seule fois dans le dossier du projet.

Commandes 
mkdir mon-projet
cd mon-projet
git init
git status
Clonage

Récupérer un dépôt

Pour travailler depuis une URL GitHub.

Commandes 
git clone https://github.com/USER/REPO.git
cd REPO
git status

2) Workflow quotidien

Le cycle minimal : add → commit → push, sans se tromper.

Cycle

Add / Commit / Push

Commandes 
git status
git add .
git commit -m "Message clair"
git push

3) Branches & merge

Isoler une fonctionnalité, puis fusionner proprement.

Workflow 
git checkout -b feature/ma-feature

# ... modifications ...

git add .
git commit -m "Ajoute X"
git checkout main
git merge feature/ma-feature
git push
